View Source Bookmarklet

在 Safari 點一下，查看網頁原始碼。支援語法高亮、搜尋、DOM/Source 切換。

📖 查看原始碼

把上方按鈕拖曳到書籤列即可安裝（桌面版瀏覽器）

功能

  • 🎨 語法高亮（Prism.js）
  • 🔢 行號顯示
  • 🔍 即時搜尋，顯示匹配數量
  • 🔄 DOM / Source 切換：當前 DOM 或伺服器原始 HTML
  • 🌓 深色 / 淺色主題
  • ✨ Beautify 美化壓縮過的 HTML
  • 📋 一鍵複製

iOS Safari 安裝步驟

  1. 隨便加任一個網頁到書籤
  2. 進「書籤」→ 編輯剛建的書籤
  3. 標題改成「查看原始碼」
  4. 網址欄整個刪掉，貼上下方程式碼
  5. 存檔


  
桌面 Safari / Chrome / Firefox

  
把書籤列叫出來（Cmd+Shift+B），直接拖上方按鈕到書籤列即可。
