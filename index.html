常見問題

      
先看看是否已經有答案。


      

        DOM 跟 Source 模式有什麼差別？
        
DOM 是當前頁面經過 JavaScript 修改後的 DOM 結構，反映你「看到」的內容；Source 透過 fetch 重新取得伺服器原始回傳的 HTML，反映「下載到」的內容。對於 SPA 或大量動態渲染的網站，兩者差異會很明顯。

      


      

        為什麼在某些網站（如 GitHub）功能變少了？
        
這些網站設定了嚴格的 Content Security Policy（CSP），阻擋了從 CDN 載入的 Prism.js 跟 js-beautify。本工具會自動偵測並降級——語法高亮與美化會被停用，但原始碼仍可正常檢視、搜尋、複製，並顯示提示訊息說明原因。

      


      

        Source 模式顯示「抓取失敗」？
        
可能原因：（1）頁面需要登入而 fetch 沒帶 cookie；（2）站台設定了 CSP connect-src 限制；（3）跨來源請求被擋。DOM 模式不受這些影響，可以改用 DOM 模式。

      


      

        會收集我的資料嗎？
        
不會。整個工具在瀏覽器本機執行，沒有任何 analytics、tracking 或外部 API 呼叫。唯一的網路請求是從公開 CDN（cdnjs.cloudflare.com）載入 Prism.js 與 js-beautify。原始碼開源在 GitHub，可自行檢視驗證。

      


      

        可以離線使用嗎？
        
目前版本依賴 CDN 載入語法高亮與美化函式庫，需要網路連線。若有離線需求，可從 GitHub 下載完整版本自行打包所有依賴。
